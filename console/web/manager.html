MCPクライアントで SSE を選択し、上の URL と Authorization: Bearer <トークン> を設定します。クライアント側でサーバー証明書を信頼してください。

          

            OpenCode の SSE 設定
            
SSEに対応するOpenCodeで、クライアントの環境変数 WINDOWS_CONSOLE_MCP_TOKEN にトークンを設定します。

            

            
          

        

      

      

        OpenCode
        
VMホストのリポジトリ直下で OpenCode を開きます。同梱の opencode.json が接続を登録します。opencode mcp list で windows-console が接続済みか確認してください。

        
設定を手動で追加する場合は、既存のプロジェクト設定に次の内容を統合します。

        
{
  "mcp": {
    "servers": {
      "windows-console": {
        "type": "local",
        "command": ["bash", "-c", "repo=$(git rev-parse --show-toplevel) && exec \"$repo/console/mcp/start.sh\""]
      }
    }
  }
}

        
        
別端末からは次の SSH 設定を使い、vm-host を SSH の接続先に置き換えます。VMホストに ~/.local/bin/windows-console-mcp の起動リンクが必要です。

        
{
  "mcp": {
    "servers": {
      "windows-console": {
        "type": "local",
        "command": ["ssh", "-T", "-o", "BatchMode=yes", "vm-host", ".local/bin/windows-console-mcp"]
      }
    }
  }
}

        
      

      
Codex CLIをVMホストで使う場合は、リポジトリ直下で実行します。

      
codex mcp add windows-console -- "$(pwd)/console/mcp/start.sh"

      
      
別端末から接続する場合は、SSHのホスト名を置き換えてください。ホスト側には ~/.local/bin/windows-console-mcp の起動リンクが必要です。

      
codex mcp add windows-console -- ssh -T -o BatchMode=yes vm-host .local/bin/windows-console-mcp

      
      

        その他のstdio対応MCPクライアント
        
クライアントのMCP設定に追加し、起動スクリプトをホスト上の絶対パスに置き換えます。

        
{
  "mcpServers": {
    "windows-console": {
      "command": "/path/to/windows/console/mcp/start.sh",
      "args": []
    }
  }
}

        
      

      
接続を追加したら、エージェントで vm_inventory を呼び出せることを確認します。
